# ApexSales - Sales Analytics Dashboard

A responsive, single-page sales analytics dashboard built with vanilla HTML, CSS, and JavaScript.

## Features
- **Real-Time KPIs**: Total Revenue, Net Profit, Completed Orders, Average Order Value (AOV), and Success Rate.
- **Interactive Visualizations**:
  - Revenue & Profit Trajectory (Monthly trend)
  - Revenue by Category (Doughnut distribution)
  - Acquisition Channels (Horizontal bar comparison)
  - Sales Rep Leaderboard (Performance metrics)
- **Persistent Data**: Powered entirely by `localStorage` with zero backend requirement.
- **Full Transaction Management**:
  - Record new sales with modal validation.
  - Cycle transaction status (Completed / Pending / Refunded).
  - Delete records with confirmation.
  - Printable invoice/receipt view.
- **Data Export & Import**:
  - Export filtered records to CSV.
  - Backup & restore dataset via JSON.
  - Reset to realistic seed dataset at any time.
- **Zero CSS Variables**: Built with direct CSS properties.

## Getting Started
Simply open `index.html` in any modern web browser.
